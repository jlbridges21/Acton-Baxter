# Generation Prompt Set

These assets were created with the built-in image-generation workflow using `originals/reference/Dexter.png` as the identity reference.

## Shared specification

- Use case: `stylized-concept`
- Asset: transparent 2x2 web-animation sprite sheet
- Subject: Dexter, the exact warm golden-brown and white voxel dog in the reference
- Preserve: centered white forehead blaze, white muzzle/chest, amber-brown eyes, black nose, floppy ears, friendly expression, blue bandana, and yellow A emblem
- Layout: equal square cells in row-major order, consistent camera/scale/lighting, complete figure and props within each cell, no dividers
- Constraints: genuinely transparent background; dog anatomy only; no readable text, extra characters, watermark, or cropped elements

## Sheet-specific prompts

1. **Idle:** attentive stance; blink and pant; curious signal-detecting head tilt; eager tail-wag ready pose.
2. **Walk right:** four natural right-facing dog gait phases with ear bounce and tail rhythm.
3. **Walk left:** four natural left-facing dog gait phases with ear bounce and tail rhythm.
4. **Work:** laptop dashboard work, monitor analysis, printed-report review, and satisfied return to dashboard work.
5. **Sit down:** shift weight back, halfway lower with braced paws and curling tail, classic attentive sit; fourth cell empty.
6. **Stand up:** seated preparation, canine play-bow stretch, standing alert with tail wag; fourth cell empty.
7. **Data thinking:** sniff out a data clue, study text-free data dots and trend line, discover connected blue-and-gold insight nodes; fourth cell empty.
8. **Analytics task:** review a chart dashboard, inspect a highlighted data point with magnifier, hold a completed chart-report folder with checkmark; fourth cell empty.
